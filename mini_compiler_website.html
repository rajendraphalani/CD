Proposed System

Source Code→Lexical Analysis→Syntax Analysis→Semantic Analysis→Intermediate Code→Execution

The compiler validates and transforms the program at each stage. The Error Handler reports problems with line numbers.

Language Features & Grammar

  • Integer variables: int x; x = 10;
  • Arithmetic: + - * / and ( )
  • Relational: < > == != <= >=
  • IF ( ) { } ELSE { }
  • WHILE ( ) { }
  • PRINT expr;
stmt  -> INT ID [= expr] ;
       | ID = expr ;
       | PRINT expr ;
       | IF (cond) block [ELSE block]
       | WHILE (cond) block
cond  -> expr RELOP expr
expr  -> term {(+|-) term}
term  -> factor {(*|/) factor}
factor-> NUM | ID | (expr) | -factor
